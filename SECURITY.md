# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub: open the **Security**
tab of this repository and choose **Report a vulnerability**.

## Supported versions

Only the latest published release is supported. Security fixes ship in a new release.

## Release integrity

Releases are signed (Ed25519). The plugin verifies the signature of a downloaded zip before it installs an update.
